## 📄 Sobre o Projeto

**Diabetes Care** é um aplicativo móvel gamificado, desenvolvido como Projeto de Conclusão de Curso (TCC), com o objetivo de auxiliar usuários no tratamento e monitoramento da diabetes. Através de uma interface moderna e elementos de jogo, o app busca engajar e motivar o usuário a manter um controle glicêmico consistente e saudável.

---
## ✨ Funcionalidades Principais

* ** Glicemia**: Registro fácil e rápido dos níveis de glicose.
* ** Histórico**: Visualização clara das medições recentes.
* ** Sistema de Gamificação**: Acumule pontos, mantenha "ofensivas" (dias seguidos de medição) e desbloqueie conquistas.
* ** Perfil de Usuário**: Acompanhe suas estatísticas e progresso geral.
* ** Autenticação Segura**: Sistema de login para proteger os dados do usuário.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as seguintes tecnologias e bibliotecas:

* **React Native**: Framework para desenvolvimento de aplicativos móveis.
* **Expo**: Plataforma para facilitar o desenvolvimento e build de apps React Native.
* **Expo Router**: Sistema de roteamento baseado em arquivos.
* **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
* **TailwindCSS (via `twrnc`)**: Estilização rápida e consistente.
* **React Hook Form & Zod**: Gerenciamento de formulários e validação de schemas.
* **React Native Reanimated**: Biblioteca para animações fluidas e performáticas.
* **Context API**: Gerenciamento de estado global (autenticação).

## 🚀 Começando

Para executar este projeto localmente, você precisará ter algumas ferramentas instaladas em sua máquina.

### Pré-requisitos

* [Node.js](https://nodejs.org/en/) (versão LTS recomendada)
* [pnpm](https://pnpm.io/installation) (gerenciador de pacotes)
* [Git](https://git-scm.com/)
* O aplicativo **Expo Go** no seu smartphone ou um emulador Android/iOS.

### ⚙️ Instalação e Execução

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/seu-usuario/seu-repositorio.git](https://github.com/seu-usuario/seu-repositorio.git)
    cd seu-repositorio
    ```

2.  **Instale as dependências com pnpm:**
    ```bash
    pnpm install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    pnpm start
    ```

4.  **Acesse o aplicativo:**
    * Após iniciar o servidor, um QR Code aparecerá no terminal.
    * Abra o aplicativo **Expo Go** no seu celular e escaneie o QR Code.
    * Alternativamente, você pode executar em um emulador pressionando `a` (Android) ou `i` (iOS) no terminal.
